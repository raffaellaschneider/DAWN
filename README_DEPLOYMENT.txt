DAWN WEBSITE - STATIC HOSTING / PUBLICATION CHECKLIST

Files: upload the contents of this directory (including assets/) to a static web host.
GitHub Pages: create a repository, upload index.html, styles.css, script.js and assets/, then enable Pages (Deploy from a branch / main / root). No build step is needed.

BEFORE PUBLIC RELEASE
1. Request and insert the official footer label from InfoSapienza: "Progetto a cura del Dipartimento di Fisica - Sapienza Universita di Roma". Replace the visible placeholder in index.html with the supplied image, including an accurate alt text. Do not reconstruct the official logo.
2. Confirm the placement and reproduction requirements for the MUR/FIS3 institutional funding banner.
3. Run accessibility tests on the deployed URL: keyboard, screen reader, 200%-400% zoom, mobile, color contrast, meaningful figure descriptions and an automated WCAG audit. Make any legally required accessibility statement through the prescribed channel. This package is NOT a certification of AgID compliance.
4. Confirm legal notices, site responsibility, privacy information and any hosting-specific logs/cookies with the relevant institutional offices. This static version has no analytics, forms, tracking scripts or advertising.
5. Review figure reuse permissions and attribution on a paper-by-paper basis.
6. Notify Comitato Editoriale Web of publication and URL, as requested by the Sapienza conditions.
7. Enable two-factor authentication on the hosting account; use least-privilege collaborators and maintain backups.
8. If the site is later modified to use analytics, forms, embedded video or other third-party services, reassess privacy/cookie requirements.

This project is an independent website external to uniroma1.it, subject to the Sapienza external project website conditions.
